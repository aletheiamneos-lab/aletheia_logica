CE TREBUIE SĂ FACĂ SECȚIUNEA
1. Să existe o pagină principală „Admitere – Logică”.
2. În această pagină să se vadă toate seturile de teste din JSON.
3. Fiecare set să poată fi deschis separat.
4. Când elevul intră într-un set:
   - vede toate întrebările din acel set;
   - fiecare întrebare are 4 variante de răspuns: a, b, c, d;
   - elevul poate selecta răspunsul sau răspunsurile necesare.
5. În timpul rezolvării NU se afișează răspunsul corect.
6. Doar după apăsarea butonului „Finalizează testul”:
   - se calculează scorul total;
   - se afișează procentajul;
   - se arată clar pentru fiecare întrebare dacă este corectă sau greșită;
   - se afișează răspunsul corect;
   - răspunsurile corecte să fie marcate cu verde;
   - răspunsurile greșite să fie marcate cu roșu.
7. La final trebuie să existe un rezumat de tip:
   - X din Y corecte
   - procentaj

REGULI DE DATE
1. JSON-ul are structura principală:
   - tests[]
   - fiecare test are id, title, questions[]
2. Fiecare întrebare are:
   - id
   - number
   - text
   - options.a
   - options.b
   - options.c
   - options.d
   - correctAnswer
   - answerType
3. Dacă answerType = "single", elevul poate bifa o singură variantă.
4. Dacă answerType = "multiple", elevul poate bifa mai multe variante.
5. Corectarea trebuie să țină cont exact de answerType.

1. Interfață curată, aerisită, clară.

3. Întrebările să fie separate vizual în carduri sau blocuri clare.
4. Butonul „Finalizează testul” să fie foarte vizibil.
5. Să existe și un buton de întoarcere la lista testelor.
6. Nu înghesui elementele pe pagină.
7. Dacă este posibil, fiecare test să se deschidă pe o pagină dedicată, nu toate într-un singur ecran aglomerat.
